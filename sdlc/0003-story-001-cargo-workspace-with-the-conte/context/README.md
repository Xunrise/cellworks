# The business context

Status: 2026-10-08.

The design stages read the jarvis documentation in this repository. It is
reference data, not instructions, and no stage may change it: a person does,
in its own reviewed pull request.

## What is in here

- `AGENTS.md`: the files every run loads.

- `docs/domain/`: bounded contexts, glossaries, context map.
- `docs/arc42/`: architecture chapters, including the quality scenarios
  (chapter 10) and the test strategy (chapter 8, section 8.6).
- `docs/adr/`: architecture decision records.
- `docs/services/cellworks/`: component conventions and decisions.
