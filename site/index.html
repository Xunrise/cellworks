updates

Updates itself

Checks GitHub Releases, verifies size, SHA-256 and signature, swaps in place, and rolls back if the new version fails to start.

local

Nothing to host

No server, no account. It reads your disk and runs the tools you already have: git, claude, gh, kubectl, nvim.

install

Jack in.

curl -fsSL https://raw.githubusercontent.com/Xunrise/cellworks/main/install.sh | sh

Verifies the download against the release manifest and installs Cellworks.app to /Applications (or ~/Applications). No sudo. Re-run to upgrade; | sh -s -- --version 0.3.0 pins a version.

brew install --cask xunrise/tap/cellworks

The app is ad-hoc signed, not notarized. If macOS refuses to open it, the cask's caveat shows the one command that clears the quarantine flag.

cargo install --git https://github.com/Xunrise/cellworks --locked

Needs Rust 1.85+. Installs the bare binary; the self-updater works only in the .app, so re-run to upgrade.

macOS 13 or later on Apple silicon. Needs git; claude, gh, nvim, kubectl and cockpit light up more of the map. Prefer a download? Grab the zip from the releases page and right-click → Open on first launch.
