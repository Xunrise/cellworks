// native map for engineers · macOS

Your projects, code, agents and tickets. One map.

Cellworks draws every project on your machine as a zoomable city: folders become districts, files become towers, functions become floors. Your Claude Code sessions walk to the files they touch, and tickets open as cases you take from problem to prototype to review.

curl -fsSL https://raw.githubusercontent.com/Xunrise/cellworks/main/install.sh | sh
Install Cellworks View on GitHub

MIT · macOS 13+ on Apple silicon · no server, no account, no telemetry

01 · the city

Read a codebase from above.

Districts for folders, towers for files, floors for functions, tests in the cellar. Zoom from the whole project down into one tower. Lenses rearrange the same city by folders, imports, calls, co-change or your bounded contexts, and lanes show what imports or calls what.

  • L next lens
  • G import lanes
  • A call lanes
  • E explorer

02 · the factory floor

Flip to 2D with one key.

The flat view lays the same project out as a floor plan seen from straight above: halls for folders, machines for files. Selection, Explorer and panels carry over, and every project remembers which view you left it in.

  • V city ↔ flat
  • F fit
  • Enter / Esc layer in / out

03 · tickets as cases

From ticket to frozen plan, on the map.

One panel lists tickets from Jira, Cockpit, GitHub and Linear. Open one as a case: Claude ingests it into problems tied to real files and functions, you prototype it in a worktree with the app running, iterate in rounds, freeze, plan and review.

  • T tickets
  • ingest → prototype → freeze → plan → review

04 · the launcher

Every project, one keystroke away.

A keyboard-first palette of every git repository under your project folders and on the hosts you reach over ssh, with branch, size and open tickets at a glance.

  • ⌘K search
  • j/k move
  • ⌘, settings

sessions

Agents on the map

Claude Code sessions show up on the towers they read and write. Follow and steer them from the sessions pane.

history

Why was this built?

Select a tower or floor: the why panel shows the commits, pull requests and stories behind each line.

review

Pull requests as cities

Press P to open a pull request as its own city at the head, compared against the merge base.

lenses

Ask, and the map reshapes

The lens panel asks Claude a question about the project and builds a lens that answers it.

updates

Updates itself

Checks GitHub Releases, verifies size, SHA-256 and signature, swaps in place, and rolls back if the new version fails to start.

local

Nothing to host

No server, no account. It reads your disk and runs the tools you already have: git, claude, gh, kubectl, nvim.

install

Jack in.

curl -fsSL https://raw.githubusercontent.com/Xunrise/cellworks/main/install.sh | sh

Verifies the download against the release manifest and installs Cellworks.app to /Applications (or ~/Applications). No sudo. Re-run to upgrade; | sh -s -- --version 0.3.0 pins a version.

brew install --cask xunrise/tap/cellworks

The app is ad-hoc signed, not notarized. If macOS refuses to open it, the cask's caveat shows the one command that clears the quarantine flag.

cargo install --git https://github.com/Xunrise/cellworks --locked

Needs Rust 1.85+. Installs the bare binary; the self-updater works only in the .app, so re-run to upgrade.

macOS 13 or later on Apple silicon. Needs git; claude, gh, nvim, kubectl and cockpit light up more of the map. Prefer a download? Grab the zip from the releases page and right-click → Open on first launch.
