# Navigation — glossary

Terms specific to this context. Shared terms and cross-context collisions are in
[`../../glossary.md`](../../glossary.md).

| Term | Definition | Source | Notes |
|------|------------|--------|-------|
| History | Back and forward through views: project, camera, folder view, selection. | prototype-findings L91, L212 |  |
| Inspection distance | The zoom at which a framed node fills about half the view, close enough to read its name. | prototype-findings L159-167; STORY-004 | reached with Enter on a node |
| Item menu | The pop-up on a node (Space or right-click) with only that node's connections and actions. | prototype-findings L55, L175-180 |  |
| Layer | A level of detail: Universe, Project, Directory or File; follows from selection and zoom. | prototype-findings L53, L143-150 | layer names are display labels; Directory holds groups, File holds one node |
| Movement mode | How h/j/k/l move: spatial (nearest node in a direction) or list order. | prototype-findings L154-156 |  |
| Palette | ⌘K search over projects, groups, nodes and sessions, listing every action once you type. | prototype-findings L182 |  |
| Selection | The node the keyboard acts on, shown with a pulsing outline. | prototype-findings L54, L173 | also called cursor |
| Tree | The per-layer explorer (E) that frames the map on the row under its cursor. | prototype-findings L56, L186-204 |  |
