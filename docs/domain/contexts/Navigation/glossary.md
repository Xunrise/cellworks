# Navigation — glossary

Terms specific to this context. Shared terms and cross-context collisions are in
[`../../glossary.md`](../../glossary.md).

| Term | Definition | Source | Notes |
|------|------------|--------|-------|
| Cables shown | Whether the cables of the masts are drawn; toggled with M, off at first, kept across a lens switch. With a selection, only the cables of the buildings inside it. | architecture prototype 2026-10-13; STORY-066 |  |
| Explorer | The project's whole file tree beside the map, grouped by the active lens, searchable by name, folding and unfolding folders, marking files and folders with uncommitted changes; its cursor row is the selection, framing the row's folder or node; open by default when a project is open, Cmd+B (E also) hides and shows it. | STORY-089 |  |
| History | Back and forward through views: project, camera, folder view, selection. | prototype-findings L91, L212 |  |
| Inspection distance | The zoom at which a framed node fills about half the view, close enough to read its name. | prototype-findings L159-167; STORY-004 | reached with Enter on a node |
| Item menu | The pop-up on a node (Space or right-click) with only that node's connections and actions. | prototype-findings L55, L175-180 |  |
| Layer | A level of detail: Universe, Project, Directory or File; follows from selection and zoom. | prototype-findings L53, L143-150 | layer names are display labels; Directory holds groups, File holds one node |
| Lens chips | The row of lens chips in the Explorer's header: the current one marked, each explained on hover; replaces the lens bar. | STORY-089 |  |
| Movement mode | How h/j/k/l move: spatial (nearest node in a direction) or list order. | prototype-findings L154-156 |  |
| Palette | ⌘K search over projects, groups, nodes and sessions, listing every action once you type. | prototype-findings L182 |  |
| Review mode | Reviewing a pull request: at most one at a time; Esc, the back control or "Leave review" leaves it before any other step, even from inside a tower; opening any project, including starting another review, also ends it. Leaving reopens the project's own city. | STORY-022 |  |
| Selection | The node the keyboard acts on, shown with a pulsing outline. | prototype-findings L54, L173 | also called cursor |
| Turned camera | The camera turned, as the zoom closes in, from looking from the corner to facing one facade; zooming out turns it back. | facade-camera prototype 2026-10-11; STORY-045 |  |
| Underground view | The view in which the cellar is within reach and the city above steps back; toggled with U, or held with Shift. | facade-camera prototype 2026-10-11; STORY-048 |  |
| Walk | Stepping from a faced facade to the next tower of its block with the arrows, scrolling a tall facade first. | facade-camera prototype 2026-10-11; STORY-046 |  |
