# Cart glossary

- **Cart item** - a product with a quantity.
- **Subtotal** - sum of line totals before shipping.
- **Total** - subtotal plus shipping.
- **Promo code** - a code such as `SAVE10` that takes a percentage (5 to 50) off the subtotal, capped at 100 EUR.
  Codes are case-insensitive. The discount is shown on the total and recorded on the order.
